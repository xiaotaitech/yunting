## Why

用户要求：历史记录存本地，并参考 Claude App 优化交互。具体确认为三类数据与三类交互：

- 书架与收听进度**只存本机**，不再往网盘 `/apps/yun_audiobook/library.json` 同步。同步带来的是一个用户看不见的后台写网盘动作、一个「立即同步」按钮和一套合并规则，而实际使用是单台手机。
- 网盘目录列表缓存在本机：「添加书籍」每次进来都要整盘扫描 1–3 秒，按目录浏览每层都要等网络。先显示上次的结果，后台再刷新。
- 「添加书籍」的搜索词记在本机，下次点一下就能再搜。
- 交互参考 Claude App：主屏只有一个页面（书架），左侧抽屉放「最近收听」（像 Claude 的会话列表），底部导航去掉；视觉换成暖色米白底、陶土橙强调色、无阴影描边卡片；补转场与触感反馈。

## What Changes

- **BREAKING** 删除网盘同步：`LibrarySync`、`LibrarySnapshot`、同步按钮、「我的 → 立即同步」、登录后从网盘恢复；`CloudDriveSource` 去掉读写状态文件两个方法。网盘上已有的 `library.json` 不删、不读。
- 本地库 v3 → v4，新增 `drive_cache` 表（键 → JSON + 抓取时刻）。网盘的整盘媒体扫描与按目录浏览走「先缓存、后刷新」；退出登录时清空。本机媒体（MediaStore）读得很快，不缓存。
- 搜索历史：存在本地键值表，最多 10 条，最近在前；搜索框为空时以标签显示，可单条删除、可清空。
- 导航：去掉底部三栏与「历史」页；主屏为书架，左上角菜单或从左边缘右滑打开抽屉。抽屉：添加书籍（主按钮）、离线管理、最近收听（按天分组、点开续播、可清空）、底部「我的」入口。
- 视觉：新主题（亮 / 暗两套），书架右上角「＋」取代悬浮按钮；页面转场改为淡入前推；播放 / 暂停、加入书架、长按进入管理加触感反馈。

## 不做

- 收听历史的搜索、单条删除入口。
- 引入自定义字体（安装包离 jsDelivr 20MiB 上限只剩约 1.6MiB）。
- 删除网盘上已有的同步文件。
