## Why

三步走的第 ②：网盘里除了有声书还有大量课程视频（实测 181 个文件夹、2075 个视频）。
定位从「网盘听书」扩展为「网盘听书 + 课程学习」。工程地基（refactor-app-foundation）已经备好
媒体类型与播放内核接口，这里在其上接入视频。

## What Changes

- 识别视频文件；含视频的文件夹认领为「课程」，文案按类型用「课」。
- 「添加书籍」分「有声书 / 课程」两栏，课程栏列出全部含视频的文件夹。
- 视频走百度转码流（M3U8）：取流时完成非会员的 8 秒广告等待（adToken），M3U8 落成本地文件
  交给播放器，分片直连百度；分片地址约 8 小时失效，失效后重取并回到原位置。
- 新增视频内核（video_player / ExoPlayer），与音频内核组合成同一个 MediaEngine；
  进度、续播、卡死恢复、睡眠定时、历史、同步全部复用。
- 视频播放页：画面、进度、±15 秒、倍速、选集、横屏全屏、自动下一课；退到后台声音继续。
- 设置：视频清晰度 720p（默认）/ 480p。
- 课程条目不提供离线下载（转码流无法离线）。

## 不做

- 视频离线缓存、字幕、手势调亮度/音量、画中画、投屏。

## Impact

- 新依赖 video_player（与 just_audio 同为 ExoPlayer；安装包增量 < 1MB，仍在 jsDelivr 20MB 内）。
- `CloudDriveSource.resolveMedia` 增加 path 与媒体类型参数（百度转码接口按路径取流）。
- 库表无变化（media_kind / kind 列在 v3 已就位）。
